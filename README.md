# Public news site bundle

Bu klasör GitHub Pages için hazırlanmış ilk yayın paketidir.

İçerik:

- kamuya açık kaynaklardan derlenen haber arşivi,
- kategori ve arşiv filtreleri,
- günlük bültenden gelen günün kavramı,
- statik HTML, CSS, JavaScript ve JSON dosyaları.

Bu pakette Tech Radar, şirket içi proje bilgisi, proje talep formu, n8n workflow'u, credential, API anahtarı, gönderim geçmişi veya çalışan bilgisi bulunmamalıdır.

Tech Radar ve proje talep alanı, erişim kontrollü bir iç yayın ortamı bulunana kadar bu pakete eklenmez.
